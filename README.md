# Jayaram H. — Personal Portfolio

A responsive, single-page personal portfolio built with semantic HTML, CSS and lightweight JavaScript interactions.

## Files
- `index.html` — page structure and content
- `style.css` — layout, visual design, responsive rules and print styles
- `script.js` — navigation, archery interaction, filters, accordions and small UI behaviours
- `assets/profile.jpg` — profile photograph

## Design decisions
The visual system uses a forest-green and warm-ivory palette with muted terracotta accents. Playfair Display is used for editorial headings, DM Sans for body copy, and Space Grotesk for labels and data. The layout uses consistent spacing, clear hierarchy, contrast, alignment and responsive grids.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Deployment
The site is hosted as a static website using GitHub Pages.
